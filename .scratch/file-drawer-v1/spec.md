# 文件抽屉 第一版 Spec

Status: ready-for-agent
Feature: file-drawer-v1
来源：`DESIGN.md`（2026-11-07 定稿，Q1—Q23 已确认）

## Problem Statement

用户在日常工作中频繁需要取得文件，但为此切到 Finder、找到目录、再拖回来，会反复打断手头的工作。文件分散在几个固定常用的文件夹里，每次重新导航到同一个子目录、重新排序、重新翻找同名文件，都是重复劳动。用户真正需要的不是又一个文件管理器，而是在任何应用上方随时唤出、取完就走的一个入口。

## Solution

一个常驻菜单栏、Dock 中不显示的 macOS 应用。鼠标悬停屏幕顶部中央或按全局快捷键，即可在顶部中央展开「文件抽屉」：左侧是用户添加的「常用文件夹」，右侧是当前「浏览位置」的内容。用户可以排序、搜索整个「搜索范围」、选中文件后拖到其他应用，或直接打开、预览、复制。操作结束后抽屉自动收起，键盘焦点回到原来的应用。文件整理操作仍然回到 Finder 完成。

## User Stories

1. **首次启动**：作为首次打开应用的用户，我想看到添加「常用文件夹」的引导，以便我不需要先读文档就知道下一步做什么。
2. **添加**：作为用户，我想通过按钮选择一个真实文件夹加入「常用文件夹」，以便我只保留日常真正会用到的入口。
3. **拖入添加**：作为用户，我想把文件夹直接拖到侧栏来添加，以便添加动作更顺手。
4. **管理入口**：作为用户，我想拖动左侧入口调整顺序，以便把最常用的放在最上面。
5. **移除入口**：作为用户，我想移除一个入口，以便侧栏不被临时项目占满。
6. **移除不删文件**：作为用户，我移除入口后，原来的目录和里面的文件必须原封不动，以便我不必担心误删。
7. **悬停唤出**：作为正在其他应用里工作的用户，我想把鼠标移到屏幕顶部中央就展开抽屉，以便不用离开当前应用。
8. **悬停不抢焦点**：作为正在打字的用户，我想悬停展开时不抢走键盘焦点，以便我的输入继续进入原来的应用。
9. **快捷键唤出并聚焦**：作为用户，我想按全局快捷键展开抽屉并直接聚焦搜索框，以便用键盘一气呵成地找文件。
10. **快捷键收起**：作为用户，我想在抽屉展开时再次按快捷键把它收起，以便快速回到原来的界面。
11. **点击进入抽屉**：作为用户，我想点击抽屉里的文件或搜索框后焦点才进入抽屉，以便我明确知道键盘输入现在去了哪里。
12. **离开自动收起**：作为用户，我想鼠标离开面板 500 毫秒后抽屉自动收起，以便它不会一直挡在前面。
13. **移回取消收起**：作为用户，我想在等待收起期间把鼠标移回来就取消收起，以便我不会因为手抖丢失当前状态。
14. **操作期间不收起**：作为用户，我在拖放、预览或右键菜单进行中时，抽屉不能自动收起，以便操作不被打断。
15. **点击外部收起**：作为用户，我想点击面板外部立即收起抽屉，以便它符合浮层的直觉。
16. **Esc 分级返回**：作为用户，我想按 Esc 先关掉预览或菜单，再按才收起抽屉，以便一次 Esc 不会连带丢掉整个上下文。
17. **焦点归还**：作为用户，我想抽屉收起后键盘焦点回到之前的应用，以便我继续原来的工作。
18. **快捷键可改**：作为用户，我想在设置里修改或禁用全局快捷键，以便它不和我其他工具冲突。
19. **注册失败提示**：作为用户，如果快捷键注册失败，我想看到明确提示让我换一个，以便我不会以为功能坏了。
20. **多屏唤出**：作为有多块屏幕的用户，我想在任意一块屏幕顶部中央都能唤出抽屉，包括没有刘海的屏幕。
21. **单实例**：作为用户，同一时间只应显示一个抽屉，以便我不会看到两个重叠的面板。
22. **跟随触发屏幕**：作为用户，悬停时抽屉应在触发的那块屏幕展开，按快捷键时在鼠标所在屏幕展开。
23. **共享内容**：作为用户，各屏幕应共用同一组「常用文件夹」和浏览状态，以便我不用在每块屏幕上重新配置。
24. **全屏可用**：作为用户，我想在普通应用的全屏空间里也能唤出抽屉，以便演示、写代码等场景不被打断。
25. **位置固定**：作为用户，我想让面板固定在屏幕顶部中央，以便它形成稳定的肌肉记忆。
26. **尺寸记忆**：作为用户，我想调整面板宽高且下次保持不变，以便适配我的屏幕和内容量。
27. **小屏适配**：作为用户，当屏幕放不下时面板应自动收缩，以便窗口不会跑到屏幕外。
28. **浏览内容**：作为用户，我想在右侧看到当前「浏览位置」里的文件和文件夹，以便快速定位目标。
29. **路径与返回**：作为用户，我想在顶部看到当前路径并能返回上一级，以便知道自己在哪、随时往回走。
30. **记住浏览位置**：作为用户，我想每个「常用文件夹」分别记住上次浏览到的子目录，以便再次展开时直接回到原处。
31. **紧凑列表**：作为用户，我想默认看到图标、名称、修改时间的紧凑列表，以便一屏能看到更多项目。
32. **文件夹优先**：作为用户，我想文件夹排在文件前面，以便先进入目录再看文件。
33. **默认按修改时间**：作为用户，我想默认按修改时间降序排列，以便最近动过的文件出现在最上面。
34. **切换排序**：作为用户，我想按名称或修改时间排序并切换升降序，以便按当下需要重新组织列表。
35. **记住排序**：作为用户，我想每个「常用文件夹」分别记住排序选择，以便不同用途的文件夹保持各自的习惯。
36. **隐藏隐藏文件**：作为用户，我默认不想看到隐藏文件，以便列表不被系统文件干扰。
37. **显示隐藏文件**：作为用户，我想在设置里打开显示隐藏文件，以便偶尔处理配置目录。
38. **包目录作为整体**：作为用户，我想把 `.app` 之类的包目录当成一个完整项目显示，以便我不会误入内部结构。
39. **搜索整个范围**：作为用户，我想搜索当前「常用文件夹」及其全部子文件夹的名称，以便我不用先导航到正确目录。
40. **搜索不缩范围**：作为用户，我当前浏览到子目录时，搜索范围不应缩小，以便我仍然能搜到同文件夹其他位置的文件。
41. **结果显示路径**：作为用户，我想在搜索结果里看到每一项所在的路径，以便区分同名文件。
42. **搜索不穿包**：作为用户，搜索不应进入包目录内部，以便结果不出现一堆无意义的内部文件。
43. **搜索不越界**：作为用户，搜索不应沿替身或符号链接跳出「搜索范围」，以便范围始终可预期。
44. **不搜内容、不搜全盘**：作为用户，我希望搜索只匹配名称且只限当前「搜索范围」，以便结果快且可控。
45. **单击选中**：作为用户，我想单击选中一个项目，以便再进行下一步操作。
46. **双击打开**：作为用户，我想双击文件用默认应用打开，以便不必先离开抽屉。
47. **双击进入**：作为用户，我想双击文件夹进入，以便连续浏览。
48. **空格预览**：作为用户，我想按空格预览选中项目，以便不打开应用也能确认内容。
49. **多选**：作为用户，我想用 Command 多选或 Shift 连续选择，以便一次处理多个文件。
50. **拖出取用**：作为用户，我想按住项目拖到聊天软件、浏览器上传区或 Finder，以便把文件直接交给目标应用。
51. **批量拖出**：作为用户，我想把多选的项目一起拖出，以便一次交付多个文件。
52. **拖出为复制**：作为用户，我希望拖出始终是复制语义，以便原文件不会因为拖放被移动走。
53. **复制到剪贴板**：作为用户，我想用 Command + C 把选中文件放到剪贴板，以便在目标应用里粘贴。
54. **右键菜单**：作为用户，我想通过右键菜单打开、预览、在 Finder 中显示、复制到剪贴板、复制路径，以便常用动作不必记快捷键。
55. **交给 Finder 整理**：作为用户，我想通过「在 Finder 中显示」完成重命名、删除、移动、新建目录，以便第一版不承担文件整理功能。
56. **入口失效保留**：作为用户，当外接盘断开、目录被删或权限失效时，入口应保留并显示具体原因，以便我知道出了什么事而不是入口凭空消失。
57. **失效可恢复**：作为用户，我想对失效入口重试、重新选择文件夹或移除，以便权限恢复后能继续用。
58. **不自动跳走**：作为用户，失效时应用不应自动切换到其他文件夹，以便我不会在不知情时操作错目录。
59. **内容变化刷新**：作为用户，浏览期间文件增删改后列表应刷新，以便我看到最新内容。
60. **操作失败保留位置**：作为用户，操作失败时应说明原因并保留当前「浏览位置」，以便我不用重新导航。
61. **云端按需**：作为用户，我不想应用主动批量下载云端文件，以便不浪费流量和时间。
62. **云端等待状态**：作为用户，实际取用云端文件时我想看到等待和失败状态，以便知道是在下载而不是卡死。
63. **菜单栏常驻**：作为用户，我想从菜单栏打开抽屉、进入设置、退出应用，以便没有 Dock 图标也能控制它。
64. **登录启动**：作为用户，我想选择是否登录时自动启动，且默认关闭，以便我自己决定常驻行为。
65. **键盘优先**：作为偏好键盘的用户，我想唤出后直接输入即可搜索、用方向键移动、回车打开，以便全程不碰鼠标。

## Implementation Decisions

### 平台与构建形态

- 目标平台：当前 Apple Silicon Mac + macOS 环境；第一版只保证本机验收。
- 构建采用 Swift Package Manager，两个 target：一个纯逻辑库（核心），一个可执行程序（应用壳）。第一版不引入 Xcode 工程，也不依赖 `xcodebuild`，因为当前机器只有 Command Line Tools。
- 应用以 `.app` bundle 形式产出，bundle 的组装（Info.plist、图标、签名占位）由脚本完成。`LSUIElement` 为 true，因此 Dock 中无图标、菜单栏有常驻项。
- 若后续安装完整 Xcode，可再引入工程文件；这属于可逆调整，不改变核心模块边界。

### 模块划分

核心库对外只暴露一个门面，内部按职责分为四个协作对象，AppKit 层不直接触碰文件系统以外的业务规则：

| 模块 | 职责 |
| --- | --- |
| 文件夹库 | 「常用文件夹」集合、顺序、增删、失效状态、持久化 |
| 目录浏览器 | 列表内容、文件夹优先、排序、隐藏文件、包目录处理、路径导航 |
| 搜索器 | 在「搜索范围」内按名称递归匹配、结果附带所在路径、边界约束 |
| 面板状态机 | 唤起、收起、焦点、交互暂停、Esc 分级的纯状态转移 |

应用壳负责：面板窗口、悬停热区、全局快捷键、菜单栏项、拖放源、Quick Look、设置界面、登录启动。这些是薄适配层，不承载可测的决策逻辑。

### 核心数据模型

- **常用文件夹条目**：稳定标识、显示名、安全作用域书签、失效状态、排序规则、浏览位置。
- **浏览位置**以相对于「常用文件夹」根目录的路径分量数组保存，而不是绝对路径；这样根目录被移动或用书签重新解析后仍能恢复。
- **条目**：文件 URL、名称、是否目录、是否包、修改时间、类型标识。包目录的 `是否目录` 为真但 `是否包` 也为真，浏览与搜索都把它当叶子。
- **排序规则**：第一键（名称／修改时间）+ 方向（升／降）。文件夹组与文件组各自应用同一规则，组间顺序恒为文件夹在前。
- 名称比较使用本地化的、忽略大小写与变音符号的标准比较；修改时间相同时按名称再按 URL 兜底，保证排序稳定。
- **失效状态**：正常、目录不存在、权限不足、所在卷不可用。每种都带可读原因与可执行的恢复动作。

### 文件访问契约

- 核心通过一个文件访问接口读取目录、取元数据、判断包与符号链接、解析书签。生产实现是 `FileManager` 的薄包装；测试实现用于构造真实环境难以复现的失效与云端场景。
- 生产实现默认不跟随符号链接与替身：列目录时用不解析链接的枚举方式，判断是否为链接后再决定是否展示为叶子。
- 所有读取失败都转换为失效状态而不是抛到 UI 层；UI 只负责呈现原因和动作。

### 持久化

- 单一份带版本号的 JSON，存放在 Application Support 下，原子写入并做 500 毫秒合并，避免拖动排序时频繁落盘。
- 内容包含：文件夹库（书签、顺序、失效状态、每项排序规则与浏览位置）、面板宽高、全局快捷键配置、显示隐藏文件开关、登录启动开关。
- 应用启动时解析全部书签；解析失败不删除条目，而是标记失效并保留原因。书签在成功访问后刷新，以降低过期概率。
- 写入失败不阻断使用，只在设置里提示「状态未保存」，下次变更时重试。

### 面板状态机

状态：隐藏、悬停待定、可见、待收起、交互保持。

| 当前状态 | 事件 | 下一状态 | 效果 |
| --- | --- | --- | --- |
| 隐藏 | 悬停进入顶部热区 | 悬停待定 | 记录 250ms 截止时间 |
| 悬停待定 | 时间到达截止 | 可见 | 在触发屏幕展开，不抢焦点 |
| 悬停待定 | 悬停离开 | 隐藏 | 取消计时 |
| 可见 | 指针离开面板 | 待收起 | 记录 500ms 截止时间 |
| 待收起 | 指针回到面板 | 可见 | 取消计时 |
| 待收起 | 时间到达截止 | 隐藏 | 若焦点曾在面板内则交还原应用 |
| 可见／待收起 | 拖放开始、预览打开、菜单打开 | 交互保持 | 取消收起计时 |
| 交互保持 | 最后一个交互结束 | 可见 | 指针在面板外则立即转入待收起 |
| 隐藏 | 快捷键按下 | 可见 | 在鼠标所在屏幕展开并聚焦搜索框 |
| 可见／待收起 | 快捷键按下 | 隐藏 | 交还焦点 |
| 任意非隐藏 | 点击面板外部 | 隐藏 | 交还焦点 |
| 任意非隐藏 | Esc 且预览或菜单打开 | 不变 | 关闭预览或菜单 |
| 任意非隐藏 | Esc 且无预览无菜单 | 隐藏 | 交还焦点 |

- 状态机不持有真实定时器；时间由外部注入，测试可手动推进。所有计时都以「截止时间 + 当前时间」判断，不做嵌套延时。
- 隐藏时记录「展开前的前台应用」，收起时若焦点在面板内则重新激活该应用；若它已退出则不做任何激活动作。

### 悬停与快捷键

- 悬停热区不使用全局鼠标监听（避免辅助功能权限提示），改为每块屏幕顶部中央放一个极矮的透明无边框窗口，用跟踪区域检测进入与离开。热区窗口不接收点击、不显示、不进入窗口循环的可见列表。
- 全局快捷键使用不需要辅助功能权限的系统热键注册；注册失败时在设置里显示具体原因并提供重新录入。
- 快捷键默认 Control + Option + F，可改可禁用；同一组合被占用时保留旧配置并提示冲突。

### 多屏与几何

- 全程只创建一个面板窗口；切换屏幕时改变其所在屏幕与位置，而不是新建窗口。
- 依据 NSScreen 的可见区域做顶部居中定位，并把刘海或菜单栏占位计入安全内边距。
- 宽高为全局记忆值，按屏幕可见区域夹取；夹取后不覆盖用户设定值，回到大屏时恢复原值。
- 面板窗口参与所有空间（含全屏空间），不激活应用、不夺走键盘焦点，只有被点击后才成为键盘窗口。

### 焦点策略

- 展开时只把窗口前置，不调用成为主窗口的方法；搜索框聚焦只在快捷键唤出、点击搜索框、或用户明确要求键盘操作时发生。
- 收起时按状态机规则交还焦点；拖放进行中不发生活跃应用切换，避免拖放目标丢失。

### 列表、排序与特殊项目

- 默认排序：修改时间降序。文件夹组与文件组分别排序后拼接。
- 隐藏文件开关为全局设置，默认关闭；关闭时列表和搜索都不出现隐藏项目，开启后两者同时出现。
- 包目录在列表中显示为单个项目，双击用默认应用打开、不进入；搜索不递归进入包内部。
- 符号链接与替身作为叶子展示，可打开与拖出，但浏览与搜索都不跟随其目标。
- 目录内容变化通过监视当前「浏览位置」的目录本身来感知，变更事件合并 200 毫秒后刷新；面板重新显示时也强制刷新一次。

### 搜索

- 只在当前选中的「常用文件夹」内递归，范围不随「浏览位置」缩小。
- 匹配规则：文件名子串、忽略大小写与变音符号；不匹配路径中的父目录名，不搜文件内容。
- 结果继承当前排序规则，并附带相对于「常用文件夹」根目录的路径用于区分同名项。
- 输入去抖 150 毫秒；新查询立即取消上一次遍历；遍历在后台进行并增量回传，不阻塞列表滚动。
- 搜索期间不预下载云端文件，只读取元数据。

### 取用

- 双击文件用系统默认应用打开；双击文件夹进入并把该位置写回该「常用文件夹」的浏览位置。
- 空格使用系统预览；预览打开时进入「交互保持」。
- 拖出使用文件 URL 的复制语义，多选时一次性携带全部 URL；不预下载云端文件，由目标应用按需触发。
- Command + C 写入文件 URL 到剪贴板，遵循标准粘贴行为。
- 右键菜单固定五项：打开、预览、在 Finder 中显示、复制到剪贴板、复制路径；多选时只保留可批量执行的项。
- 第一版不提供拖出移动、不提供重命名／删除／移动／新建目录。

### 失效、变化与云端

- 失效入口永不自动移除、永不自动切换；错误以内联横幅呈现，包含原因与「重试／重新选择／移除」。
- 恢复动作执行后重新解析书签并尝试恢复原「浏览位置」；若原位置不存在则停在「常用文件夹」根目录并说明原因。
- 权限类失败在用户重新选择同一目录后应恢复，不产生重复条目。
- 云端文件只在实际取用（打开、预览、拖出、复制）时按需获取，并在条目上显示等待或失败；等待期间不阻塞其他条目操作。

### 常驻与设置

- 菜单栏菜单包含：打开抽屉、设置、退出。
- 设置项：全局快捷键、显示隐藏文件、登录启动、面板尺寸重置、状态文件位置说明。
- 登录启动默认关闭，通过系统登录项服务实现；失败时提示且不改变开关状态。
- 应用退出前做一次同步落盘。

### 错误呈现

- 所有用户可见错误使用「发生了什么 + 可以做什么」两段式，不显示原始错误码作为主文案；原始信息可复制到剪贴板供排查。
- 列表级错误不影响侧栏；侧栏级错误不影响其他「常用文件夹」。

## Testing Decisions

### 什么算好测试

- 只测外部可观察行为：给定目录内容与一串事件，断言用户能看到什么（列表顺序、搜索结果、面板可见性、焦点归属、持久化结果），不断言内部方法调用、私有结构或实现顺序。
- 每个测试自建临时目录并在结束时清理；不依赖开发机上的真实文件。
- 时间相关的断言一律通过注入的时间源推进，不使用真实等待，保证测试快且不抖动。
- 文件系统失效、云端等待等无法稳定复现的场景通过测试用文件访问实现构造，不靠改系统权限硬造。

### 被测模块

全部打在核心库门面上，覆盖四类行为：

| 主题 | 代表性用例 |
| --- | --- |
| 目录浏览 | 文件夹在前；两种键的升降序；修改时间相同按名称兜底；隐藏文件开关前后；包目录显示为叶子且不可进入；符号链接不跟随；空目录；无权限子目录只影响自身 |
| 搜索 | 命中子目录深层文件；同名结果带不同路径；范围不随浏览位置缩小；不进入包；不穿越符号链接；忽略大小写与变音符号；空查询恢复普通列表；查询切换时取消旧遍历 |
| 状态与记忆 | 添加／排序／移除入口；移除后原目录内容不变；每个入口独立记住浏览位置与排序；根目录被移动后按书签恢复；失效状态分类与三种恢复动作；持久化往返与写入失败降级 |
| 面板状态机 | 250ms 前离开不展开；到点展开且不夺焦点；500ms 后收起；移回取消；拖放／预览／菜单期间不收起；结束后重新计时；Esc 两级；快捷键开关切换；点击外部立即收起；隐藏后焦点归还 |

### 测试工具与先例

- 使用 Swift Testing（`import Testing`）而不是 XCTest：当前只有 Command Line Tools，XCTest 框架不随附，Swift Testing 随 Swift 工具链提供，`swift test` 可直接无头运行。
- 本仓库此前无任何测试，本 spec 确立第一批先例：按主题分文件、用例名用行为句（例如「修改时间相同时按名称排序」），一个用例只断言一个行为。
- 命名与目录约定随首个实现落地；后续测试沿用同一形态。

### 明确不自动测的部分

以下按 `DESIGN.md` 的原型验证清单人工验收，不写自动化测试：拖放投递到 Finder／聊天软件／浏览器上传区、NSPanel 定位与多屏行为、全局快捷键注册、焦点交还的实际效果、Quick Look 呈现、普通全屏应用中的唤出与遮挡。这些依赖真实窗口服务器与外部应用，自动化收益低且易碎。

## Out of Scope

- 发行、签名、公证、自动更新、崩溃上报。
- Intel Mac、旧版 macOS、其他操作系统的兼容性。
- 文件整理：重命名、删除、移动、新建目录、标签、批量重命名。
- 拖出移动语义。
- 文件内容搜索、全盘搜索、索引与增量索引。
- 分组、标签、收藏、最近访问、智能文件夹等超出「常用文件夹」的组织概念。
- 多窗口、多面板同时显示、画中画或独立窗口模式。
- 云端文件的主动预下载、离线缓存管理。
- 多用户、共享配置、配置导入导出。
- 本地化到中文以外的语言（界面语言暂定中文）。

## Further Notes

- `DESIGN.md` 是本 spec 的唯一设计来源，Q1—Q23 的确认结论已经内化到上面的用户故事与实现决策中；两者冲突时以 `DESIGN.md` 为准并回来修正本 spec。
- 术语严格遵循 `GLOSSARY.md`：「文件抽屉」「常用文件夹」「浏览位置」「搜索范围」「取用」。实现与测试命名不应引入该表里标注为 Avoid 的同义词。
- 原型验证的六项（`DESIGN.md` 技术方向一节）是开发后的验收工作，不是本 spec 的实现前置条件；但第 1、2、4 项若验证失败，会改变面板与拖放层的实现决策，届时另开 spec。

- 250／500 毫秒是起始参数，允许试用后调整；调整只改状态机输入的默认值，不改状态转移。
