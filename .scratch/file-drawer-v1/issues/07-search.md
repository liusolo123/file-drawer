# 07: 搜索：整个「搜索范围」内按名称查找

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 在搜索框输入时，应用在当前「常用文件夹」及其全部子文件夹内按名称查找；即使正在浏览某个子目录，范围也不缩小。结果显示所在路径以区分同名项。搜索不进入包目录、不沿符号链接越界、不搜文件内容；连续输入时旧遍历被取消；清空查询回到普通列表。

**Blocked by:** 03 浏览：目录内容、路径、进入与返回、浏览位置记忆

**Status:** ready-for-agent

- [ ] 搜索覆盖当前「常用文件夹」的全部子文件夹，不随「浏览位置」缩小
- [ ] 结果显示相对路径，同名文件可以区分
- [ ] 不进入包目录内部，不沿符号链接或替身跳出范围
- [ ] 匹配忽略大小写与变音符号，且只匹配名称
- [ ] 输入去抖 150 毫秒；新查询取消上一次遍历，旧结果不会覆盖新结果
- [ ] 清空查询恢复普通列表并保留原「浏览位置」
- [ ] 单测覆盖深层命中、同名不同路径、包与链接边界、去抖与取消

## Comments

### 2026-11-10 实现完成，等待人工验收

核心库：

- `SearchMatch`：命中项 + 相对于「常用文件夹」根目录的父目录路径分量。
- `SearchEngine`：迭代式深度遍历，范围始终是整个常用文件夹；`isBrowsable` 保证不进入包目录、不沿符号链接／替身越界；隐藏文件按开关处理；只匹配名称，忽略大小写与变音符号。
- `SearchCancellation`：线程安全的取消标记；每个目录读取失败只跳过该目录，不中断整次搜索。
- 结果沿用当前排序规则。

应用层：

- 搜索框接入 `NSSearchFieldDelegate`，输入去抖 150ms。
- 每次查询递增代数，旧遍历通过取消标记立即停止，完成回调再校验代数，旧结果不会覆盖新结果。
- 搜索结果显示相对路径（根目录显示「根目录」），同名项目可区分；tooltip 给出绝对路径。
- 清空查询或点返回恢复原「浏览位置」；双击搜索结果中的文件夹会跳到它并进入。
