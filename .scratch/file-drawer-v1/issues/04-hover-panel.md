# 04: 悬停唤出与自动收起状态机

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 鼠标移到屏幕顶部中央满 250 毫秒，抽屉展开，且原应用的键盘输入继续正常工作；鼠标离开面板 500 毫秒后收起，期间移回则取消。拖放、预览、右键菜单进行中不自动收起，结束后恢复收起规则。本票先只处理主屏；每屏热区留给 10。

**Blocked by:** 01 应用骨架与菜单栏唤出空面板

**Status:** ready-for-agent

- [ ] 悬停热区不足 250 毫秒即离开时不展开
- [ ] 停留满 250 毫秒后在触发屏幕展开，且不在其他应用里打字时不抢焦点
- [ ] 鼠标离开面板 500 毫秒后收起；期间移回则取消收起
- [ ] 进入「交互保持」（拖放、预览、菜单）期间不自动收起，最后一个交互结束后恢复收起规则
- [ ] 状态机不持有真实定时器，时间由外部注入
- [ ] 单测用注入时间覆盖全部状态转移，不使用真实等待
- [ ] 隐藏时若焦点在面板内，交还展开前的前台应用
