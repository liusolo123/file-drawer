# 02: 常用文件夹：添加、排序、移除、重启恢复

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 用户第一次启动看到添加提示，选一个真实文件夹加入「常用文件夹」，侧栏出现入口；可以拖动调整顺序，也可以移除入口。移除后原目录和内容保持不变。退出再启动，入口和顺序都还在。失效状态的完整呈现留给 11，这里只保证解析失败不丢条目。

**Blocked by:** 01 应用骨架与菜单栏唤出空面板

**Status:** ready-for-agent

- [ ] 首次启动显示添加提示，添加第一个「常用文件夹」后提示消失
- [ ] 可通过按钮选择一个文件夹加入，侧栏显示其名称
- [ ] 拖动可调整入口顺序，重启后顺序不变
- [ ] 移除入口后原目录与其中内容完全不变，侧栏不再显示该入口
- [ ] 重启后按安全作用域书签重新解析，入口与顺序恢复
- [ ] 解析失败时保留条目并标记失效，不静默删除
- [ ] 单测覆盖添加、排序、移除、书签往返（临时目录）
