## Comments

### 2026-11-13 实现完成并验收通过

核心库：

- `HotkeySpec` + `HotkeyModifiers`：Carbon 位值、可读标签、显示名与「至少一个主修饰键」校验。
- `DrawerSettings.hotkey` 纳入状态文件；旧文件缺少该字段时回退默认 ⌃⌥F。
- 快捷键与尺寸等设置随状态文件往返。

应用层：

- 设置窗口：快捷键录入／启用开关／冲突提示、显示隐藏文件、登录时启动、重置面板尺寸、状态文件位置。
- 录入期间临时注销全局热键；Esc 取消录入。
- 登录启动使用 `SMAppService.mainApp`，默认关闭；失败时不改变开关并提示。当前以 ad-hoc 签名从 `dist/` 运行，若系统拒绝注册会按失败路径提示，安装到 `/Applications` 后可用。
- 保存失败时菜单栏出现「状态未保存 — 点此重试」，不阻断使用；下次变更自动重试；退出前同步落盘。
- 菜单栏新增「设置…」。

验收中修复：

- ⌘Space 等系统保留组合在应用收到按键前就被系统截走，原逻辑无法报冲突。改为检测录入期间窗口失焦且应用不再活跃，取消录入并提示。
