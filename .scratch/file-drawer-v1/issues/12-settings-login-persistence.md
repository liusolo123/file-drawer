# 12: 设置、登录启动与持久化健壮性

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 一个设置窗口，承载全局快捷键的录入、禁用与冲突提示，显示隐藏文件开关，登录启动开关（默认关闭），以及面板尺寸重置。状态写入失败时提示「状态未保存」并在下次变更时重试，不阻断使用；退出前完成一次同步落盘。

**Blocked by:** 05 全局快捷键与焦点交还；06 排序切换、隐藏文件、包目录与符号链接；10 多屏、面板几何与全屏空间

- [ ] 「显示隐藏文件」开关与列表、搜索的生效路径一致
- [ ] 登录启动默认关闭，可开启；失败时不改变开关状态并说明原因

## Comments

### 2026-11-12 实现完成，等待人工验收

核心库：

- `HotkeySpec` + `HotkeyModifiers`：Carbon 位值、可读标签、显示名与「至少一个主修饰键」校验。
- `DrawerSettings.hotkey` 纳入状态文件；旧文件缺少该字段时回退默认 ⌃⌥F。
- 快捷键与尺寸等设置随状态文件往返。

应用层：

- 设置窗口：快捷键录入／启用开关／冲突提示、显示隐藏文件、登录时启动、重置面板尺寸、状态文件位置。
- 录入期间临时注销全局热键，避免按键先触发抽屉；Esc 取消录入。
- 登录启动使用 `SMAppService.mainApp`，默认关闭；失败时不改变开关并提示。
- 保存失败时菜单栏出现「状态未保存 — 点此重试」，不阻断使用；下次变更自动重试；退出前同步落盘。
- 菜单栏新增「设置…」。

自动验证：`swift test` 83/83（新增 6 条：默认显示、禁用、修饰键校验、往返、旧文件兼容、只读目录写入失败）。
