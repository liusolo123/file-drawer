# 05: 全局快捷键与焦点交还

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 在任何应用前台时按 Control + Option + F，抽屉展开并直接把焦点放进搜索框，可以直接键入；抽屉展开时再按一次收起，键盘焦点回到原来的应用。快捷键注册失败时给出明确、可操作的提示。修改与禁用快捷键留给 12。

**Blocked by:** 04 悬停唤出与自动收起状态机

**Status:** done

- [x] 默认快捷键在任意应用前台时都能唤出，且不触发辅助功能权限请求
- [x] 唤出后搜索框获得焦点，键入内容直接进入搜索框
- [x] 抽屉展开时再次按快捷键收起，焦点交还给展开前的前台应用
- [x] 注册失败时显示可操作提示，不静默失效
- [x] 单测覆盖快捷键触发的状态转移（隐藏 → 可见并聚焦、可见 → 隐藏）

## Comments

### 2026-11-10 实现完成并验收通过

核心库：

- `PanelStateMachine` 新增 `.hotkeyPressed`：隐藏或悬停待定时展开并聚焦搜索框；可见或待收起时收起，并按是否获得过焦点决定交还焦点；交互保持期间忽略。

应用层：

- `HotkeyCenter`：Carbon `RegisterEventHotKey` 注册 Control + Option + F，不请求辅助权限；注册失败返回状态，由启动流程提示。
- 注册失败时弹出可操作提示：说明组合可能被占用、建议退出占用应用后重启，并说明自定义快捷键后续提供。
- `PanelController.focusSearchField()`：延后一拍把第一响应者设为搜索框，确保窗口已成为键盘窗口。
- `BrowserView` 新增搜索框（本票只负责聚焦，过滤逻辑在 07 实现）。

自动验证：`swift test` 44/44（新增 4 条快捷键转移用例）。启动后无可见窗口，说明热键注册成功、未弹出失败提示。

用户人工验收通过：任意应用唤出、聚焦搜索框、再次按下收起并交还焦点、Esc 收起、点击外部不夺焦点，均正常。
