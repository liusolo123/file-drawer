# 11: 失效、目录变化与云端文件

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 外接盘断开、目录被删除或权限失效时，入口保留并显示具体原因，提供重试、重新选择文件夹、移除三个动作；恢复后回到原「浏览位置」。浏览期间文件发生变化时列表自动刷新；操作失败时说明原因并保留当前位置。云端文件不主动批量下载，实际「取用」时才按需获取并显示等待与失败。

**Blocked by:** 03 浏览：目录内容、路径、进入与返回、浏览位置记忆

**Status:** ready-for-agent

- [ ] 外接盘断开、目录被删除、权限失效三种情况都能识别并显示可读原因
- [ ] 失效入口永不自动移除、永不自动跳转到其他「常用文件夹」
- [ ] 重试、重新选择、移除三个动作都可用；重新选择同一目录后恢复且不产生重复条目
- [ ] 恢复后回到失效前的「浏览位置」；原位置不存在时停在根目录并说明
- [ ] 浏览期间目录内容变化后列表自动刷新（事件合并 200 毫秒）
- [ ] 云端未下载文件在打开、预览、拖出、复制时按需获取，显示等待与失败状态
- [ ] 失败操作保留当前「浏览位置」，列表级错误不影响侧栏
- [ ] 错误文案采用「发生了什么 + 可以做什么」两段式
- [ ] 单测用桩文件访问覆盖四类失效与恢复路径

## Comments

### 2026-11-12 实现完成，等待人工验收

失效与恢复：

- `FolderStatus` 增加 `recoverySuggestion`，错误呈现改为「发生了什么 + 可以做什么」两段式。
- 右栏新增恢复视图：原因、建议与「重试／重新选择…／移除入口」三个动作。
- `FolderLibrary.replaceFolder(id:with:)`：保留入口 id、顺序与排序规则，换书签、更新名称与状态、重置浏览位置，不产生重复条目。
- 入口失效时永不自动移除、不自动跳转；侧栏保留警告图标与 tooltip。

目录变化：

- 为当前「浏览位置」建立 vnode 监视，内容变化 200ms 合并后自动刷新。
- 面板每次显示时强制刷新一次（`PanelController.onShow`）。
- 搜索状态下暂停自动刷新，避免打断结果。

云端文件：

- 列表通过 `.isUbiquitousItemKey` / `.ubiquitousItemDownloadingStatusKey` 标记未下载项，显示 iCloud 图标。
- 打开或预览未下载文件时按需调用 `startDownloadingUbiquitousItem`，顶部提示「正在从 iCloud 下载…」，下载完成后执行原动作；失败时提示具体文件名。
- 拖出与复制不预下载，由目标应用按需触发。
