# 11: 失效、目录变化与云端文件

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 外接盘断开、目录被删除或权限失效时，入口保留并显示具体原因，提供重试、重新选择文件夹、移除三个动作；恢复后回到原「浏览位置」。浏览期间文件发生变化时列表自动刷新；操作失败时说明原因并保留当前位置。云端文件不主动批量下载，实际「取用」时才按需获取并显示等待与失败。

**Blocked by:** 03 浏览：目录内容、路径、进入与返回、浏览位置记忆

**Status:** done

- [x] 外接盘断开、目录被删除、权限失效三种情况都能识别并显示可读原因
- [x] 失效入口永不自动移除、永不自动跳转到其他「常用文件夹」
- [x] 重试、重新选择、移除三个动作都可用；重新选择同一目录后恢复且不产生重复条目
- [x] 恢复后回到失效前的「浏览位置」；原位置不存在时停在根目录并说明
- [x] 浏览期间目录内容变化后列表自动刷新（事件合并 200 毫秒）
- [x] 云端未下载文件在打开、预览、拖出、复制时按需获取，显示等待与失败状态
- [x] 失败操作保留当前「浏览位置」，列表级错误不影响侧栏
- [x] 错误文案采用「发生了什么 + 可以做什么」两段式
- [x] 单测用桩文件访问覆盖四类失效与恢复路径
