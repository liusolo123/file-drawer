## Comments

### 2026-11-10 实现完成并验收通过

核心库：

- `SortRule`：键（名称／修改时间）× 方向（升／降），默认修改时间降序。
- `CommonFolder.sortRule`：每个「常用文件夹」独立记忆，旧状态文件缺少该字段时用默认值。
- `DirectoryBrowser.contents(of:sortRule:showHiddenFiles:)`：文件夹恒在前，组内按规则排序；修改时间相同时按名称、再按路径稳定兜底。
- `DirectoryEntry.isSymbolicLink`：符号链接与替身不再参与进入；包目录同样按叶子处理。
- `FolderAccess.contents(of:includingHidden:)`：隐藏文件开关下沉到读取层。
- `DrawerSettings.showsHiddenFiles` 纳入状态文件；旧文件缺少该字段时默认关闭。

应用层：

- 右栏顶部新增排序下拉框，四种组合即时生效并写回该「常用文件夹」。
- 菜单栏新增「显示隐藏文件」勾选项，切换后立即刷新列表并持久化。
- 包目录双击交给默认应用，不进入；符号链接显示为链接图标，不作为可进入目录。
