# 06: 排序切换、隐藏文件、包目录与符号链接

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 用户可以按名称或修改时间排序并切换升降序，每个「常用文件夹」分别记住自己的选择；隐藏文件默认不显示，可在设置中开启；`.app` 之类的包目录作为完整项目显示且双击不进入；符号链接与替身可以显示和取用，但浏览不跟随其目标。

**Blocked by:** 03 浏览：目录内容、路径、进入与返回、浏览位置记忆

**Status:** ready-for-agent

- [ ] 名称／修改时间 × 升序／降序四种组合都正确，文件夹组与文件组各自应用同一规则
- [ ] 修改时间相同时按名称、再按 URL 兜底，排序稳定
- [ ] 每个「常用文件夹」独立记住排序选择，重启后恢复
- [ ] 隐藏文件默认不显示，开启后列表出现
- [ ] 包目录显示为单个项目，双击交给默认应用，不进入内部
- [ ] 符号链接与替身可作为叶子展示和拖出，浏览不跟随
- [ ] 单测覆盖四种排序组合、稳定兜底、包与链接边界
