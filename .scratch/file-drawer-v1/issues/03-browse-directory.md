# 03: 浏览：目录内容、路径、进入与返回、浏览位置记忆

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 点选一个「常用文件夹」，右侧显示它的直接内容；文件夹在前、文件在后，组内默认按修改时间降序。双击文件夹进入，顶部显示当前路径，可以返回上一级。每个「常用文件夹」独立记住上次「浏览位置」，切回或重启后回到原处。

**Blocked by:** 02 常用文件夹：添加、排序、移除、重启恢复

**Status:** ready-for-agent

- [ ] 选中「常用文件夹」后右侧显示其直接内容，不递归展开
- [ ] 文件夹恒在文件之前，组内默认按修改时间降序
- [ ] 双击文件夹进入，顶部路径同步更新，返回可回到上一级
- [ ] 每个「常用文件夹」独立记住「浏览位置」，切换或重启后恢复
- [ ] 目标位置已不存在时退回该「常用文件夹」根目录并说明原因，不崩溃
- [ ] 空目录与「尚未添加任何常用文件夹」都有明确空状态
- [ ] 单测覆盖列出内容、文件夹优先、默认排序、浏览位置记忆
