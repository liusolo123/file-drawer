## Comments

### 2026-11-09 实现完成

核心库新增：

- `DirectoryEntry` / `DirectoryBrowser`：只列直接子项；文件夹优先、修改时间降序；时间相同时按名称与路径稳定兜底；包目录按叶子处理。
- `CommonFolder.browsingPath`：相对于根目录的路径分量；自定义解码保证缺少该字段的旧状态文件仍可读。
- `FolderLibrary`：`browsingPath(for:)`、`setBrowsingPath(_:for:)`、`resolveBrowsingLocation(for:)`；记录位置失效时回退根目录并重置。

应用层新增：

- 右侧 `BrowserView`：返回按钮、路径栏、文件列表、空目录与错误提示。
- 双击文件夹进入、返回上一级；切换「常用文件夹」恢复各自位置。
- 隐式状态变化（保存失败、外部删除）由 `resolveBrowsingLocation` 兜底。

自动验证：`swift test` 25/25（新增 8 条），覆盖直接子项、排序、稳定兜底、包装处理、隐藏文件、位置记忆与回退、旧状态文件兼容。

构建脚本改为独立 `.build-app` 目录，避免 release 构建与 `swift test` 争用 SwiftPM 宏插件缓存。
