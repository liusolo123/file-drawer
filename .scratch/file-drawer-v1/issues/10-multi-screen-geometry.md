## Comments

### 2026-11-12 实现完成，等待人工验收

多屏与全屏：

- 热区随鼠标所在屏幕计算，任意屏幕顶部中央都能唤出；快捷键在鼠标所在屏幕展开。
- 全程只有一个面板窗口，切换屏幕是移动而非新建。
- `collectionBehavior` 保持 `.canJoinAllSpaces` + `.fullScreenAuxiliary`，用于普通全屏空间。

尺寸：

- 面板右下角新增缩放把手，拖动调整宽高，顶部中央与水平居中保持不变。
- `PanelSize` 纳入状态文件：保存用户的「期望尺寸」，显示时按目标屏幕可见区域夹取（最小 480×320）。
- 夹取只在显示/拖动时生效，不覆盖期望值；回到大屏恢复原尺寸。
- 旧状态文件缺少 `panelSize` 时回退默认 720×440。

自动验证：`swift test` 72/72（新增 3 条尺寸夹取、1 条尺寸往返与旧文件兼容）。

待人工确认：多屏悬停与快捷键展开、单面板迁移、右下角缩放与重启记忆、超大尺寸夹取、全屏应用上唤出。
