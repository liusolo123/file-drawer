### 2026-11-11 实现完成，等待人工验收

核心库：

- `ContextMenuAction` + `ContextMenuPolicy`：普通文件夹不支持预览（用「打开」进入），文件、包目录与符号链接可预览；其余四项始终可用。
- 菜单可用性变成纯函数，便于后续多选扩展与测试。

应用层：

- `DrawerTableView`：空格触发预览；右键先选中鼠标所在行再询问菜单。
- Quick Look：接 `QLPreviewPanel` 数据源与 `begin/endPreviewPanelControl`；预览关闭后把键盘焦点收回抽屉，保证下一次 Esc 能收起。
- 右键菜单五项：打开、预览、在 Finder 中显示、复制到剪贴板、复制路径；按策略启用。
- 双击：文件夹进入（含搜索结果里的文件夹）；文件、包与符号链接交给默认应用。
- 交互保持：预览或菜单开始时暂停自动收起与「失焦即收起」，结束后恢复。

自动验证：`swift test` 65/65（新增 4 条菜单策略用例）。

### 2026-11-11 预览无法用 Esc/空格关闭的修复

用户反馈预览打开后 Esc 与空格都关不掉。原因是预览面板与抽屉各自是独立窗口，按键可能仍被抽屉的响应链接走（Esc 会去收起抽屉，空格会再次触发预览）。

修复：

- 新增应用级本地按键监视：预览可见时，空格（49）与 Esc（53）在进入响应链之前被拦截，直接关闭预览并恢复抽屉焦点。
- 预览打开前显式激活应用，确保按键事件进入本应用。
- 关闭预览后清空监视标记，不干扰正常输入。
