## Comments

### 2026-11-11 实现完成

核心库：

- `ContextMenuAction` + `ContextMenuPolicy`：普通文件夹不支持预览（用「打开」进入），文件、包目录与符号链接可预览；其余四项始终可用。
- 菜单可用性变成纯函数。

应用层：

- `DrawerTableView`：空格触发预览；右键先选中鼠标所在行再询问菜单。
- Quick Look：接 `QLPreviewPanel` 数据源与 `begin/endPreviewPanelControl`；预览关闭后把键盘焦点收回抽屉。
- 右键菜单五项；双击文件夹进入（含搜索结果），文件、包与符号链接交给默认应用。
- 交互保持：预览或菜单开始时暂停自动收起与「失焦即收起」，结束后恢复。

自动验证：`swift test` 65/65（新增 4 条菜单策略用例）。

### 2026-11-12 预览无法关闭的修复，验收通过

问题：预览打开后 Esc 与空格都关不掉。原因是预览面板与抽屉各自独立，按键被抽屉响应链接走。

修复：应用级本地按键监视，预览可见时拦截空格（49）与 Esc（53）；预览前显式激活应用；关闭后清除标记并收回抽屉焦点。

用户复测通过。
