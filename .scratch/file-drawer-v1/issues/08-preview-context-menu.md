# 08: 取用（一）：预览与右键菜单

Parent: `.scratch/file-drawer-v1/spec.md`

**What to build:** 单项目即可完成一次完整「取用」：空格预览、双击用默认应用打开、右键菜单提供打开、预览、在 Finder 中显示、复制到剪贴板、复制路径。预览打开期间抽屉不自动收起，关闭后恢复。Esc 先关预览，再按才收起抽屉。

**Blocked by:** 03 浏览：目录内容、路径、进入与返回、浏览位置记忆

**Status:** ready-for-agent

- [ ] 空格打开系统预览；预览中按 Esc 只关预览，再按才收起抽屉
- [ ] 双击文件用默认应用打开，双击文件夹进入
- [ ] 右键菜单包含打开、预览、在 Finder 中显示、复制到剪贴板、复制路径，且均可执行
- [ ] 「复制路径」写入可粘贴的绝对路径文本
- [ ] 预览打开期间进入交互保持，不自动收起；关闭后恢复收起规则
- [ ] 单测覆盖菜单项对文件／文件夹／包的可用性规则
